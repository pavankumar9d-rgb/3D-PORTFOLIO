# Pavan Kumar Dasari — 3D Creator Portfolio

A high-performance, dark-themed 3D Creator portfolio landing page built with **React**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

## ✨ Features

- **Dark Aesthetic**: Custom `#0C0C0C` theme with Google Fonts (*Kanit*, weights 300–900).
- **Hero Section**:
  - Full-screen height with fluid gradient typography (`.hero-heading`).
  - Interactive magnetic 3D portrait (`Magnet` component) with physics-based mouse tracking.
  - Responsive navigation with smooth scrolling.
  - Custom gradient-pill CTA button (`ContactButton`).
- **Marquee Section**:
  - Dual-row dynamic scroll-driven horizontal gallery with 21 curated 3D motion site GIFs.
  - Smooth bi-directional parallax translation on scroll.
- **About Section**:
  - Scroll-triggered character-by-character reveal typography (`AnimatedText`).
  - Absolutely-positioned corner 3D floating icons with staggered directional spring animations.
- **Services Section**:
  - Clean light contrast section (`#FFFFFF`) with massive typographic index numbers (`01`–`05`).
  - Minimalist layout detailing 3D Modeling, Rendering, Motion Design, Branding, and Web Design.
- **Projects Section**:
  - 3D sticky-stacking interactive project cards that scale down smoothly as you scroll past them.
  - Multi-column project asset showcase with custom rounded geometries and "Live Project" pill buttons.
  - Integrated contact footer.

## 🛠 Tech Stack

- **React 18**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide React**

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run local development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
